## 1. 目标、范围与验收

用户实测管理后台（`http://localhost:18080/identity/admin/`）后两项反馈驱动本次改造：

1. **权限目录看不明白**：目录页 36 项权限平铺混列——`identity:*` 18 项（租户管理员角色材料，内置角色 `tenant-admin` 已绑定 12 项）、`platform:*` 14 项（平台后台接口保护点，`principal_type='PLATFORM'`，不参与租户角色分配）、样例业务权限 4 项（PUBLISHED）。页面无分区、无来源说明、read/manage/assign 接口粒度直接暴露。
2. **界面难看**：管理页为裸 Vue 3 + vue-router，无 UI 组件库；全局 `src/app/style.css` 853 行 + 4 个组件 scoped 共约 205 行，仅 3 个 CSS 变量（`--blue/--border/--muted`），颜色多为硬编码 hex，无间距/字号/圆角体系。

范围决策（已确认方案 B，未选 A 仅目录页 / C 引组件库）：不引 UI 组件库，保持零运行时 UI 依赖与现有锁定链；通过 design token 体系系统化重写样式获得统一观感。
