## 1. 实施目标与验收

从当前仅有文档的仓库交付可复用的 Java/Python 框架：两个基础服务、两个公共包、身份管理界面、业务 examples、明确分工的 config/infra/deploy，以及从本地开发到真实多机部署的闭环。

不新增发布控制台、跨项目统一账号、菜单权限、管理 npm 包或额外公共微服务。实现阶段按依赖组织，但不得以任务分期省略完整目标合同。

以下均为待实现/待验证的验收要求，当前没有任何 AC 标为通过。

| 编号 | 场景与输入 | 可观察结果 |
| --- | --- | --- |
| AC-01 | 从发行物创建文档、聊天两个独立项目 | 公共包可从制品仓库安装；基础镜像直接复用；管理页零业务改动；配置和数据不串项目 |
| AC-02 | A/B 租户同名账号、伪造 tenant_id、跨租户 ID | 账号独立；HTTP/SQL/缓存/文件/后台访问均不越租户 |
| AC-03 | 角色并集、SELF/TENANT、委派分配与编辑、自授/受保护对象 | 数据范围与管理范围分别执行；无业务读取权也可按委派分配；越界、凭据夺取和自授拒绝 |
| AC-04 | 浏览器、外部 OAuth/OIDC、第三方提供方、机器客户端 | PKCE/回调/租户/作用域正确；内省按 client/token/audience 过滤；公开客户端无秘密与 refresh |
| AC-05 | Java↔Python、绕过 Gateway、内部双身份接口 | 双方独立鉴权；租户和 trace 传递正确；伪造头拒绝，写入不自动重放 |
| AC-06 | Outbox/Inbox 重复、断网、投递/消费中断、迟到结果 | 已提交事实可恢复；本地业务副作用不重复；未知外部结果不自动判成功或无限重试 |
| AC-07 | 真实多机注册/替换/停机、Nacos 陈旧发现、公开入口 | 发布地址可达；陈旧发现有界；内部控制面公网不可达，TLS/代理链正确 |
| AC-08 | 管理页面清单、注册三模式、业务资料初始化、权限目录发布 | 用户/角色/委派/会话/应用流程可用；新权限不自动授出；解释可信；注册不扩权，资料初始化可幂等恢复 |
| AC-09 | 禁用、撤销、改密、Redis/identity/PG 故障 | 新授权失败关闭；普通请求、长任务和流式连接按设计的各自撤权边界执行；依赖错误不匿名放行 |
| AC-10 | 框架/身份镜像/配置基线升级及恢复 | 用户和授权保持；业务 Web 不因身份页升级被重建；配置三方差异可审阅；实际恢复成功 |
| AC-11 | 双 API 同消息和同会话不同输入、双 Worker 领取 | 重复输入同结果，内容冲突 409；同会话有序，后续输入不污染当前上下文；不同会话并发 |
| AC-12 | SSE 断连、API 宕机、通知丢失、慢客户端、游标过期 | 任意 API 鉴权后回放；不新建 Run；事件不聚合；过期游标按快照重同步，终态停止重连 |
| AC-13 | Worker 失联、旧 Worker 恢复、外部工具完成但记录前崩溃 | 旧 attempt 写入失败；安全步骤受限恢复；未知副作用进入待恢复且不重复发起 |
| AC-14 | 跨节点取消/批准/撤权及跨租户 Run 访问 | 状态持久化、重复操作幂等；确认绑定输入版本；无越权输出或后续工具启动 |
| AC-15 | 多节点容量、模型预算、旧版 Run 与新 Worker | 跨节点额度有效；结果未知的调用不随意释放预算；不兼容版本不领取，排空可追踪 |
| AC-16 | 空库/旧库迁移、争锁、历史篡改、DDL/回填中断 | 锁和摘要有效；失败停止发布；回填可续跑；应用回退不 downgrade 数据库 |
| AC-17 | 两台应用机分批失败/中断、Nginx 配置/证书更新失败 | 失败停止后续批次；记录真实版本；配置先验证再切换；兼容回退且不重建基础设施 |
| AC-18 | 同字段多来源、Nacos 错误快照、配置漂移、热更新/重启字段 | 来源按设计固定；秘密/环境字段拒绝进入 Nacos；无效更新保留旧值；漂移停止覆盖；各进程报告配置摘要 |
| AC-19 | 首次安装、重复初始化、新增服务、外部依赖接入、普通应用发布 | 数据库/账号/namespace/vhost 创建且归属正确；重复不改密/删库；新增只增加指定资源；应用发布不改变组件和卷 |
| AC-20 | Windows 本地全容器→IDE 双向调用→测试镜像 | 初次链路完整可跑；宿主/容器地址与 OAuth 回调正确；调试副本不串流量；测试/生产凭据与本地隔离 |

每个检查点输出独立候选版本、精确包版本/镜像 digest、配置与迁移摘要、通过场景及未验证列表。候选制品标记 candidate，不能冒充正式稳定版；允许后续通过的同一产物晋级。仍按完整目标设计，检查点只是更早发现问题。

R-01/R-02/R-03 及其任务状态详见[范围决定](../design/01-总体架构与工程结构设计.md#decisions)。未确认前基础任务可推进，但最终范围不能封版；用户决定不纳入时须显式修订任务/AC，不能在执行时删断言。具体业务值、主机和模型容量属于项目输入，不等同于未决核心设计。

### 6.4 配置、依赖和环境专项场景

| 输入 / 操作 | 必须观察的结果 |
| --- | --- |
| 在 Nacos 提交 PG_HOST、secret 或未声明字段 | 发布校验拒绝；应用不会从远程改环境/秘密来源 |
| Nacos 配置缺失、错误快照、控制台漂移 | 首次缺必需项不 ready；运行时保留旧值；发布拒绝覆盖未知变更，摘要可查 |
| infra 初始化连续两次、然后新增第二服务 | 原密码/数据/卷不变；只增加新库/角色/消息资源；不会重跑旧业务建表 |
| 预先存在同名错误归属数据库/账号 | 停止并报告，不能删掉重建 |
| 使用外部 PG/Redis/Nacos/Rabbit | 不启动替代容器；仍验证本项目资源、权限和网络 |
| 全容器换为 Windows IDE API/Worker | 旧实例摘除、新地址可达、无同址冲突；PUBLIC_ORIGIN/内部端点不混用，登录和跨语言调用通过 |
| local/test/prod 互换 namespace/凭据/数据地址 | 初始化与发布识别目标不一致并拒绝；未持对应授权不能访问其他环境 |
| 仅发布 agent 镜像 | PG/Redis/Nacos/Rabbit 进程、digest、卷和账号保持；不触发依赖维护任务 |
| 管理机中断或第二应用主机失败 | 不继续扩大变更，逐机实际版本保留；核对后受锁保护续跑 |
| 框架基线升级而项目修改了环境文件 | 三方差异可见；保留项目地址/秘密，先测试后更新，不整体覆盖 |

### 6.5 生产入口专项场景

| 输入 / 故障 | 必须观察的结果 |
| --- | --- |
| 正确域名、未知 Host、错误证书链、内部 CA 不可信 | 正确 TLS 可访问；未知 Host 拒绝，错误证书/信任失败阻止发布，不关闭验证 |
| 没有业务 Web；不存在 API/JS 文件 | 管理页、登录和账号流程可用；不存在 API/资源为 404，不返回业务 index |
| 正常登录、外部 OAuth、Client Credentials、伪造 Forwarded/user/tenant 头 | 回调/issuer 一致，机器换 token 不被用户登录拦截；伪造身份无效 |
| 外部访问 DB/Nacos/Actuator/内部 API/内省 | 默认不可达或被拒绝；允许的私网内省仍需客户端认证 |
| 10 MiB 以上请求、上游超过 deadline、POST 返回前断连 | 明确 413/超时；代理不重放写入，不据此声称服务端未提交 |
| SSE 15 秒心跳、持续超过普通 API 超时、断连/入口 reload/镜像替换 | 事件及时到达，无缓冲聚合；按游标重连，无重复 Run；已达终态不继续重连 |
| 错误 Nginx 配置、不可达 upstream、第二主机发布失败 | 候选校验失败不切换；烟测失败停止后续批次，恢复兼容上版并记录实际摘要 |
