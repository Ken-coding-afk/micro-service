## 4. 复核结论与影响范围

| GLM 项 | 复核与处理 |
| --- | --- |
| identity 的重复 id/version | 部分成立；只清理 controller 已保证的对应条件，保留 null status、列表项版本、业务版本冲突等独立校验 |
| PermissionCatalogService 的 expectedVersion | 不成立：PermissionPublicationController 直接传入 long catalogVersion，没有负值校验，服务必须保留 |
| ServiceHttpClient 的 CancellationException 重查 | 成立；上方已提前返回，删除重试条件中的第二次判断 |
| BffMonitoring 路径检查 | 不成立：全局检查解码路径，代理限制原始路径；例如原始 %61 解码后无 %，并非同一条件，保留 |
| PlatformRedisRateLimiter | 不能删除：该适配明确修正官方限流器的故障放行行为；GatewayRateLimitTest.nativeFailOpenMarkerBecomes503EvenWhenBffIsAbsent 已有针对性场景，本轮只核查源码，未运行 Redis 集成 |
| BffIdentityClient URI / FailedInstanceFilter 实例检查 | 前者是暴露给 OAuth 客户端的 WebClient 请求白名单，后者只应对实际选中的 HTTP 实例失效；不能仅凭“来自框架”就假定所有调用/失败路径均保证这些值 |
| source_files 消费者 | 已由生成器保证的忽略目录/符号链接/越界判断可删除；保留文件类型、秘密文件与运行包筛选 |
| dev 目录 | catalog 保证范围但不保证存在；仅删除范围重复判断，保留 is_dir |
| migrate 死分支与环境变量 | 成立；实现已在脚本帮助承诺的 env-file 密码文件优先级并删除永假分支 |
| infra/init 的 _sql_quote | 无调用，删除；实际 SQL 继续用 psycopg.sql |
| publish 最后直接写状态 | 成立；统一复用原子保存，未变化项目也逐项持久化 |
| Python SDK 版本 | 成立；运行时从已安装发行元数据读取，避免维护第二份版本 |
| Python request_model 预算 | 只移除发送前的重复拒绝，保留计时和解析前后检查；解析也在总预算内 |
| Nacos 清理前路径重算 | 成立；TemporaryDirectory 已持有创建时绝对目录，不再用可能改变的 CWD 重算边界 |
| BFF 出站栈 | 有重复，但不是可直接替换的等价实现：OAuth 需要 WebClient、Basic/form、响应体时限和状态适配；本轮不扩公共 SDK 合同 |
| 租户 set_config 三处 | 代码相似，生命周期不同（带恢复的 scoped 与事务内固定 scope），不能直接合并或删除；业务认证前无 SDK 可信 principal 的路径需保留 |
| /me 成功信封 | SDK ApiErrors 统一错误，不自动包装普通成功响应；本地 IdentityApiResponses 有相同包装，属可复用点，不是漏用 SDK 导致的协议错误 |
| CallContexts.Scope.closed | 不成立；旧 scope 再关闭会覆盖后续绑定的上下文，closed 保证生命周期幂等 |
| PasswordCredentials synchronized | 未证明对象只能单线程使用；公开的一次性凭据所有权保护保留 |
| IdentityResourceErrors 的兜底异常 | action 必抛，但 Java 编译器不能据此证明泛型 attempt 不返回；删掉需要改返回语义，不为省一行改变失败关闭逻辑 |
| APP_ENV/PROJECT_CODE | getRequiredProperty 是装配依赖获取，不能都算重复校验；独立 maintenance 入口也不能假定 Spring SDK 已启动 |
| security_web token 长度、缓存 key 长度 | 入口协议限额/早拒绝和公共组件验证不一概删除；不因内部方法也校验就放松协议入口 |
| R3/R4 便利函数、长函数、锁/import/测试加载风格 | 风格与潜在重构点，不是可据此证明的行为缺陷；不按行数机械拆分，不在本轮统一 |
| R5 启动类历史注释 | 成立，移除已过期任务编号注释 |
| R6/R7 全仓干净 | 本轮未做全仓生成物历史和测试语义审计，不能背书为全仓无问题 |
