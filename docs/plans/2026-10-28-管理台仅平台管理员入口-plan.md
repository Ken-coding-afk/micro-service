| AC-04 | 从业务应用发起租户登录 | 业务认证、租户数据与底层受保护 API 不受影响 |

## 3. 设计依据与本次边界

界面设计 §1、§2 明确平台管理员单入口；认证设计保留业务租户认证。前轮“旧租户后台兼容”由本轮明确退役取代。平台选择目标租户不是切换登录身份。旧客户端登记、历史会话数据不做破坏性清理；公网租户后台命名空间永久拒绝。无数据库迁移。

## 4. 影响范围

identity-service 管理前端、SPA 路由、共享登录模板；api-gateway 公共边界；对应定向测试、设计与接入指南。仅更新独立 28080 候选，26080 环境不变。不改业务权限模型、不删除租户 API/数据、不自动提交或推送。
